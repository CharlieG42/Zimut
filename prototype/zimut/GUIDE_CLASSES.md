# Zimut — Guide des classes (pour nouveaux joueurs)

Bienvenue dans Zimut ! Chaque partie se joue avec une **équipe de 3 personnages** choisis parmi les 8 classes ci-dessous. Ce guide résume leurs caractéristiques (caracs) et leurs sorts pour bien démarrer.

## Comment lire ce guide

- **PV** : points de vie — le personnage meurt à zéro.
- **PA** : points d'action — chaque sort coûte des PA, remis à zéro à chaque tour.
- **PM** : points de mouvement — distance parcourue par tour.
- **Force** : puissance des dégâts physiques (corps à corps).
- **Intelligence** : puissance des dégâts magiques et soins.
- **Agilité** : vitesse d'attaque (jouer avant l'ennemi).
- **Sagesse** : précision et résistance aux effets.
- **Défense** : réduit les dégâts subis.

Les caracs ci-dessous sont données **au niveau 1** ; elles montent avec les niveaux (1 → 50). Les sorts se débloquent par paliers de 5 niveaux.

## Conseils pour construire votre équipe

1. **Un Tank ou Druide** en première ligne pour absorber les dégâts.
2. **Un soigneur** (Heal ou Druide) pour tenir sur la durée.
3. **Un damage dealer** (Assassin, Mage, Chasseur, Sylvain ou Invocateur) pour tuer vite.

Exemples d'équipes équilibrées : Tank + Heal + Mage (classique), Druide + Chasseur + Sylvain (nature), Invocateur + Tank + Heal (défensive).
